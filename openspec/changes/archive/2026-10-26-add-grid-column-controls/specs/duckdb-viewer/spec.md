# Spec Delta

## ADDED Requirements

### Requirement: 列头菜单与调整列宽

系统 SHALL 在每个列头提供列操作菜单，并允许用户拖动列头右边界调整该列宽度。菜单 MUST 至少提供：隐藏该列、固定/取消固定该列、重置该列宽度、重置当前对象的全部列设置。右键打开菜单 MUST NOT 改变当前排序；只有点击列头本身的排序区域才切换排序。

- 调宽 MUST 同时作用于该列的表头与所有单元格，并设有可用的最小宽度。
- 调宽 MUST NOT 触发数据库读取，也 MUST NOT 改变当前页、排序或过滤。
- 菜单 MUST 可通过键盘打开（列头获得焦点后按 Shift+F10 或菜单键），并支持方向键移动与 Esc 关闭。

#### Scenario: 右键列头打开菜单

- **WHEN** 用户右键点击某列列头
- **THEN** 系统展示该列的列操作菜单
- **AND** 当前排序、过滤与已加载的数据页保持不变

#### Scenario: 拖动改变列宽

- **WHEN** 用户按住列头右边界并左右拖动
- **THEN** 该列宽度随拖动实时变化，表头与单元格宽度一致
- **AND** 其他列的顺序与内容不变

#### Scenario: 最小列宽

- **WHEN** 用户尝试把列拖到窄于系统设定的下限
- **THEN** 列宽停在下限，列仍然可见且可再次调宽

#### Scenario: 重置列宽

- **WHEN** 用户从某列的菜单选择"重置列宽"
- **THEN** 该列恢复为默认宽度，其他列的设置不受影响

#### Scenario: 键盘打开列头菜单

- **WHEN** 列头获得键盘焦点，用户按 Shift+F10 或菜单键
- **THEN** 系统展示与右键相同的列操作菜单，并可用键盘选择菜单项

### Requirement: 隐藏与恢复列

系统 SHALL 允许用户从列头菜单隐藏当前对象的列。被隐藏的列 MUST NOT 出现在网格中，但仍属于该对象并保留其列宽、固定状态与恢复能力。

- 系统 MUST 在列头菜单中列出当前对象被隐藏的列，允许逐列恢复。
- 系统 MUST 提供一次性恢复全部隐藏列的操作。
- 当当前对象的所有列都被隐藏时，网格 MUST 展示明确的空状态，并提供恢复全部列的操作。
- 隐藏列 MUST NOT 触发数据库读取（清除当前排序列的排序这一情况除外），也 MUST NOT 改变过滤条件或已加载的行数据。
- 若被隐藏的列正是当前排序列，系统 MUST 同时清除该排序并回到第一页，以保持"排序方向在网格中可见"。

#### Scenario: 隐藏一列

- **WHEN** 用户从列头菜单选择隐藏某列
- **THEN** 该列从网格中消失，其余列顺次排列
- **AND** 当前页的行数据、过滤条件与未相关列的排序保持不变

#### Scenario: 隐藏当前排序列

- **WHEN** 用户隐藏正是当前排序依据的列
- **THEN** 系统清除排序并回到第一页
- **AND** 网格中不再显示已不可见的排序方向

#### Scenario: 恢复单个被隐藏的列

- **WHEN** 用户从列头菜单的隐藏列列表中选择某一列
- **THEN** 该列回到网格中的原始位置
- **AND** 其列宽与固定状态与隐藏前一致

#### Scenario: 全部隐藏后的空状态

- **WHEN** 当前对象的所有列都被隐藏
- **THEN** 网格展示"所有列已隐藏"的空状态与"显示所有列"操作，而不是空白网格

#### Scenario: 恢复全部列

- **WHEN** 用户选择"显示所有列"
- **THEN** 当前对象的所有列按原始顺序重新出现，并保留各自原有的列宽与固定状态

### Requirement: 固定列到左侧

系统 SHALL 允许用户将当前对象的列固定到网格左侧。固定列 MUST 排在所有未固定列之前，并保持各固定列之间的原始列顺序。网格横向滚动时，固定列 MUST 保持可见；用户取消固定后，该列 MUST 回到未固定列中的原始位置。

- 固定列 MUST 以可见方式（如列头图标或视觉分隔）与未固定列区分。
- 固定 MUST NOT 改变已保存的列宽、隐藏状态、排序、过滤或已加载的数据页。
- 若某列同时被固定和隐藏，隐藏优先；取消隐藏后该列仍保持固定。

#### Scenario: 固定一列

- **WHEN** 用户从列头菜单选择固定某列到左侧
- **THEN** 该列移动到网格左侧的固定区域，并带有可见的固定标识
- **AND** 当前页数据与排序、过滤保持不变

#### Scenario: 横向滚动时固定列保持可见

- **WHEN** 网格内容超出可视宽度，用户向右横向滚动
- **THEN** 已固定列始终留在视图左侧，未固定列正常滚过

#### Scenario: 多列固定的顺序

- **WHEN** 用户先后固定多列
- **THEN** 固定列之间按它们在对象中的原始列顺序排列，而不是按固定操作的先后顺序

#### Scenario: 取消固定

- **WHEN** 用户对已固定列选择取消固定
- **THEN** 该列回到未固定列中的原始位置，并随横向滚动正常移动

#### Scenario: 固定列被隐藏

- **WHEN** 用户隐藏一个已固定的列，随后又恢复该列
- **THEN** 隐藏期间该列不显示
- **AND** 恢复后该列重新出现在固定区域

### Requirement: 按对象记忆列布局

系统 SHALL 按"数据库文件 + schema + 对象 + 列名"保存列宽、是否隐藏与是否固定，并在用户再次查看同一对象、刷新、重新打开标签页或重启编辑器后恢复这些设置。

- 列设置 MUST 按对象隔离：同一列名在不同表或视图中互不影响，不同数据库文件中的同名对象也互不影响。
- 切换对象 MUST 立即应用目标对象已保存的设置；没有保存记录的对象 MUST 使用默认布局。
- 若保存的记录引用了已不存在的列，系统 MUST 忽略该记录而不报错；新增列 MUST 使用默认设置。
- 若保存的值不可用（如宽度非法），系统 MUST 忽略该项并使用默认值。
- 用户 MUST 能通过列头菜单重置当前对象的全部列设置，恢复默认列宽、显示全部列且不固定任何列。
- 保存列设置 MUST NOT 读取数据库，也 MUST NOT 扩大数据库占锁窗口。

#### Scenario: 切换对象后再返回

- **WHEN** 用户调整了对象 A 的列布局，切换到对象 B，再回到对象 A
- **THEN** 对象 A 的列宽、隐藏与固定状态与离开时一致
- **AND** 对象 B 未显示对象 A 的任何布局设置

#### Scenario: 重新打开标签页或重启编辑器

- **WHEN** 用户关闭该数据库的标签页，之后重新打开同一数据库并查看同一对象
- **THEN** 该对象已保存的列宽、隐藏与固定状态被恢复

#### Scenario: 不同对象中的同名列

- **WHEN** 两个对象都包含名为 `id` 的列，用户只调整其中一个对象的 `id` 列
- **THEN** 另一个对象的 `id` 列保持默认布局

#### Scenario: 对象结构变化

- **WHEN** 对象中某个有保存设置的列已不存在，或对象新增了列
- **THEN** 系统正常展示网格，忽略失效的列记录，并给新增列使用默认设置

#### Scenario: 重置当前对象的列设置

- **WHEN** 用户从列头菜单选择重置当前对象的全部列设置
- **THEN** 所有列恢复默认宽度、重新显示，且没有任何列处于固定状态
- **AND** 该对象保存的列设置被清除
